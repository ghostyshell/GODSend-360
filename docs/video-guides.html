Your library

See what is on the console.

Xbox Library

Every game found on your Xbox through Aurora, as real box art you can flip: hover a cover and the case turns in 3D. Search, sort, filter, refresh from the console and fetch missing covers.

  1. Open Xbox Library
  2. Hover a cover to flip the case
  3. Search or sort the list
  4. Refresh the library cache
  5. Download missing covers

The game page

Click a cover to open its page: publisher, developer and release date, the Aurora library entry, the Aurora assets (background, banner, icon, cover and screenshots, searched online or loaded from a file), DLC and title updates, and save games.

  1. Click a cover
  2. Open Aurora assets
  3. Find DLC and title updates
  4. Manage save games

Getting games

Find a game and send it to the console.

Browse and Download

One list over four sources: Minerva Archive over BitTorrent, Internet Archive, your own Transfer folder and dlxbgame releases. Filter by title and switch between Xbox 360, Original Xbox, XBLA, Digital, DLC and Indie.

  1. Pick a source
  2. Pick a category
  3. Filter the list by title

Toolbox

Convert and move files: ISO to GOD, ISO to XEX, BadAvatar USB and an FTP manager for the console.

  1. Open Toolbox
  2. Choose a tool

ISO to GOD

Convert Xbox 360 disc images to the Games on Demand format Aurora installs. Add ISOs, choose an output folder and convert; output is named Title Name - TitleID.

  1. Add ISOs
  2. Choose the output folder
  3. Convert

ISO to XEX

Extract a disc image to a folder with a default.xex so the game runs straight from that folder.

  1. Add the image
  2. Pick an output folder
  3. Convert

BadAvatar USB

Prepare a USB stick for the BadUpdate exploit: pick the drive, format it to FAT32, and add optional packages such as Proto, FreestyleDash and the Aurora XeUnshackle build.

  1. Pick the USB drive
  2. Set the options
  3. Choose packages
  4. Create the stick

FTP Manager

Browse the console drive over FTP: upload files or folders, make folders, cut, copy and paste, with transfer progress on the right.

  1. Open FTP Manager
  2. Browse folders
  3. Upload files
  4. Watch Transfers

Job Queue

Every download, conversion and FTP transfer in one list, with live status, progress and speed, and a cancel button for each job.

  1. Open the queue
  2. Read status and speed
  3. Cancel a job

The app

Logs and settings.

Console

The live terminal of the backend. Downloads, conversions and FTP transfers log here, and you can open the logs folder to share a log.

  1. Open Console
  2. Press Open logs folder

Settings

Choose folders, set the Xbox FTP connection, send the Aurora script to the console, export Aurora databases and refresh the dlxbgame list and caches.

  1. Set folders
  2. Save the Xbox connection
  3. Send Aurora scripts
  4. Refresh caches
